Finance Control

Projeto simples em PHP e MySQL para controle financeiro, com foco em organização de código e boas práticas.
As credenciais do banco de dados são isoladas em um arquivo de ambiente, sem uso de dependências externas.

📌 Descrição

Este projeto demonstra uma implementação básica de conexão com banco de dados utilizando PHP, separando as configurações sensíveis do código principal para facilitar manutenção e segurança.

⚙️ Requisitos

PHP 7.4 ou superior

MySQL ou MariaDB

Servidor Web (Apache, Nginx, XAMPP, etc.)

📂 Estrutura

Arquivo de ambiente para credenciais

Classe de conexão com o banco de dados

Organização simples e fácil de entender

🚀 Como usar

Configure o arquivo de ambiente com os dados do banco

Crie o banco de dados conforme a configuração

Execute o projeto no servidor web

🔐 Observações

Não versionar o arquivo de ambiente

Evitar uso do usuário root em produção

Utilizar apenas para fins educacionais ou projetos simples
